🏥 MedAlly — Agentic AI Architecture

How the Supervisor Agent orchestrates specialized tool-agents for personalized health guidance

Amazon Bedrock (Claude Sonnet 4)
Amazon DynamoDB (Health Memory)
Amazon S3 (Image Storage)
Amazon EC2 (Compute)
Request Flow — From User Input to AI Response
User Input
Patient sends message (text / voice / image)
"I started Lisinopril 3 days ago and now I have a dry cough"
Frontend — React (ChatPanel.jsx)
POST /api/chat/stream → SSE streaming connection
Sends patient_id, message, conversation_history to backend
Backend — FastAPI (main.py)
Fetches stored conversations → Passes to Orchestrator
🧠 Supervisor Agent — Orchestrator (orchestrator.py)
Builds System Prompt + Patient Context → Sends to Claude
System prompt contains: AI identity, safety rules, tool instructions, patient's medications/conditions/allergies, current date
⚡ AGENTIC LOOP (max 6 iterations)
Amazon Bedrock — Claude Sonnet 4
Claude AUTONOMOUSLY decides: respond or call tools?
Receives: system prompt + messages + 6 tool definitions
⚖️ Claude's Decision
Does Claude need more information? Does it need to save data?
YES → Call Tools
Execute Tool(s) → Return results to Claude
Claude may call 1-3 tools per iteration. Results feed back into the loop.
↩ Loop back to Claude with tool results
NO → Generate Response
Stream final text response to user
Detect urgency level → Save to DynamoDB → Exit loop
The 6 Agent-Tools (Claude calls these autonomously)
👤
get_health_profile
READ patient's medications, conditions, allergies, personal info
→ DynamoDB: Profiles table
🔍
search_health_timeline
READ past symptoms, medication changes, health events
→ DynamoDB: Timeline table
📝
log_health_event
WRITE new symptom, medication change, or health event
→ DynamoDB: Timeline table
📊
analyze_health_patterns
READ timeline + conversations to discover correlations and trends
→ DynamoDB: Timeline + Conversations
✏️
update_health_profile
WRITE name, age, medications, conditions, allergies extracted from chat
→ DynamoDB: Profiles table
📸
Skin Image Analysis
Multimodal vision — image sent inline with message to Claude
→ S3: Image bucket + DynamoDB metadata
Example: "I have a dry cough since starting Lisinopril"
1️⃣
Claude calls: get_health_profile
→ Retrieves: Metformin 500mg, Lisinopril 10mg, Type 2 Diabetes, Penicillin allergy
2️⃣
Claude calls: search_health_timeline
→ Checks: any prior cough reports? When was Lisinopril started?
3️⃣
Claude calls: log_health_event
→ Logs: "Dry cough — 3 days, likely ACE inhibitor side effect" (severity: low)
4️⃣
Claude generates response with ✅ Reassurance badge
"Dry cough is a very common ACE inhibitor side effect affecting ~10% of patients. Given you started Lisinopril just 3 days ago, this is expected. Consider asking your doctor about switching to an ARB like Losartan."
